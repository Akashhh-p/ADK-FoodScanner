# Firebase Setup Guide

This guide walks through setting up Firebase Authentication for the Food Scanner app.

## Firebase Console Setup

### 1. Create Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com)
2. Click "Create a project"
3. Enter project name: "Food Scanner App"
4. Click "Continue"
5. Disable Google Analytics (optional)
6. Click "Create project"
7. Wait for project to initialize

### 2. Add Android App

1. In Firebase Console, click "Create app" or the Android icon
2. Select "Android"
3. Enter package name: `com.example.foodscanner`
4. (Optional) Enter App nickname: "Food Scanner"
5. (Optional) Enter SHA-1 certificate fingerprint
   - Get SHA-1: Run `./gradlew signingReport` in Android Studio Terminal
   - Or: keytool -list -v -keystore ~/.android/debug.keystore
   - Password: android
6. Click "Register app"

### 3. Download google-services.json

1. After registering, download the `google-services.json` file
2. Place it in `app/` directory (root of app module)
   - Path: `app/google-services.json`
3. The file contains your Firebase configuration

### 4. Enable Authentication

1. Go to "Build" → "Authentication" in left sidebar
2. Click "Get started"
3. Select "Email/Password" provider
4. Click the toggle to enable it
5. Click "Save"

### 5. Create Test User (Optional)

1. Go to "Users" tab in Authentication
2. Click "Create user" (top right)
3. Enter:
   - Email: test@example.com
   - Password: Test@123
4. Click "Create"

## Local Configuration

### 1. Set SDK Path

Create or update `local.properties`:

```properties
sdk.dir=C:\\Users\\YourUsername\\AppData\\Local\\Android\\Sdk
```

Get your SDK path:
- In Android Studio: File → Project Structure → SDK Location
- Copy the Android SDK Location path

### 2. Update google-services.json

The `app/google-services.json` file should contain:

```json
{
  "type": "service_account",
  "project_id": "YOUR_PROJECT_ID",
  "private_key_id": "...",
  "private_key": "...",
  "client_email": "...",
  "client_id": "...",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token",
  "auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs"
}
```

This file is automatically generated by Firebase. Never commit it to version control.

## Gradle Configuration

The `build.gradle` files are already configured:

### Root build.gradle
```gradle
id 'com.google.gms.google-services' version '4.4.0' apply false
```

### App build.gradle
```gradle
id 'com.google.gms.google-services'

// Firebase dependencies
implementation platform('com.google.firebase:firebase-bom:32.7.1')
implementation 'com.google.firebase:firebase-auth-ktx'
implementation 'com.google.firebase:firebase-firestore-ktx'
```

## Troubleshooting Firebase Issues

### Issue: "Needs Auth" Error or Authentication Fails

**Causes:**
- google-services.json not in correct location
- Firebase project not created
- Email/Password provider not enabled
- Internet connection issue

**Solutions:**
1. Verify `app/google-services.json` exists and is valid JSON
2. Check Firebase Console → Authentication → Providers (Email/Password should be enabled)
3. Try creating new Firebase project
4. Check device/emulator has internet connection

### Issue: "Bad Request" (400) Error

**Causes:**
- Invalid email format
- Password less than 6 characters
- Email already registered

**Solutions:**
1. Ensure email format is valid (contains @)
2. Use password with 6+ characters
3. For testing, use unique email addresses
4. Check email not already registered in Firebase

### Issue: User Registration Works But Login Fails

**Causes:**
- Typo in email
- Password incorrect
- Database not synced

**Solutions:**
1. Check email spelling exactly matches registered email
2. Verify password hasn't been changed
3. Delete app, rebuild, and try again
4. Check Firebase Console for user account

### Issue: Gradle Sync Fails

**Causes:**
- Missing google-services.json
- Incorrect build.gradle configuration
- Dependency conflicts

**Solutions:**
1. Ensure google-services.json is in `app/` directory
2. Invalidate Gradle caches: File → Invalidate Caches → Invalidate and Restart
3. Delete `.gradle` folder in project root
4. Run `./gradlew clean build`

## Additional Firebase Features

### Enable Firestore (For Future Features)

1. Go to "Build" → "Firestore Database"
2. Click "Create database"
3. Select location: us-central1
4. Start in test mode (for development)
5. Click "Create"

### Security Rules (Production)

Update Firestore rules to restrict access:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
  }
}
```

### Enable Real-time Database (Optional)

1. Go to "Build" → "Realtime Database"
2. Click "Create Database"
3. Select region
4. Start in test mode
5. Click "Enable"

## Security Best Practices

1. **Never commit google-services.json** - Add to .gitignore (already done)
2. **Use strong passwords** - Enforce minimum 8 characters in production
3. **Enable 2FA** - In Firebase Console under Authentication settings
4. **Restrict API access** - Set up proper Firestore security rules
5. **Monitor usage** - Check Firebase Console for suspicious activity
6. **Use production build** - Disable debug logging in release builds
